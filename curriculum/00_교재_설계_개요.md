# 교재 설계 개요 – *Minjuns Weg*

## 1. 기본 콘셉트

- **통합형**: 한 챕터 안에서 *듣기/읽기로 장면을 접하고 → 문법을 발견하고 → 말하기·쓰기로 직접 써 보는* 흐름.
- **대상 학습자**: 성인 – ① **대학 유학 준비생** ② **아이를 둔 이민 가정**. 두 그룹이 모두 “내 이야기”로 느끼도록 **주인공을 두 명**으로 둡니다.
- **하나의 이야기, 두 개의 길**: 유학생 **민준**과 두 아이의 엄마 **수진**이 같은 어학원·같은 건물에서 만나 함께 독일에 정착합니다. 민준은 대학으로, 수진은 아이 학교와 간호사 자격 인정으로 – 길은 다르지만 매 과에서 서로 얽힙니다. 매 과 끝 **Tagebuch(일기)**가 다음 과로 이어지는 다리 역할을 합니다.
- **재미 장치 (학습과 직결)**: ① 44과에 걸친 **수수께끼 하나**(이웃 Frau Schulze의 1989년 사진) ② 한국인이 실제로 하는 **실수가 곧 사건** ③ 매 과 끝의 **궁금증** ④ 학생이 이야기에 참여하는 쓰기. 재미있는 장면은 반드시 그 과의 핵심 표현이 꼭 필요한 장면이어야 합니다.
- **CEFR 정렬**: 각 챕터에 CEFR Can-do(“~할 수 있다”) 목표를 적고, 레벨 마지막 챕터는 Goethe-Zertifikat 시험 형식으로 마무리합니다.
- **한국인 학습자 맞춤**: 문법 설명은 한국어로, 한국어 화자가 자주 틀리는 부분(동사 위치, 관사, 명사 대문자, 발음 등)을 따로 표시합니다.
- **첨삭 중심 쓰기**: 쓰기 과제마다 모범 답안 + 첨삭 체크리스트 + 자주 나오는 오류 예시를 넣었습니다.

## 2. 수업 회차 (주 3회 × 100분 기준)

**1차시 = 100분 (1교시 50분 + 2교시 50분) · 1주 = 3차시(300분) · 숙제 차시당 60분**

| 레벨 | 챕터 | 1과당 차시 | 본 수업 | 복습·워크숍·시험 대비 | 레벨 합계 | 기간 | 레벨 끝 시험 |
|---|---|---|---|---|---|---|---|
| **A1** | 1–8 | **3차시** (= 1주) | 24차시 | 3차시 (모의시험 1주) | **27차시 · 45시간** | **9주 (약 2개월)** | Start Deutsch 1 |
| **A2** | 9–20 | **4차시** (3과 = 4주) | 48차시 | 9차시 (A1 다지기 1주, 14과 후 복습 1주, 모의시험 1주) | **57차시 · 95시간** | **19주 (약 4.4개월)** | Goethe A2 |
| **B1** | 21–32 | **5차시** (3과 = 5주) | 60차시 | 12차시 (26과 후 복습 1주, 쓰기·말하기 워크숍 2주, 모의시험 1주) | **72차시 · 120시간** | **24주 (약 5.5개월)** | Goethe B1 |
| **B2** | 33–44 | **6차시** (1과 = 2주) | 72차시 | 15차시 (38과 후 복습 1주, 쓰기·말하기 워크숍 2주, 모의시험 2주) | **87차시 · 145시간** | **29주 (약 6.7개월)** | Goethe B2 |
| **합계** | 44과 | | 204차시 | 39차시 | **243차시 · 405시간** | **81주 (약 18.7개월)** | |

> 한 달 ≈ 4.3주로 계산. 누적: A1 수료 약 2개월 → A2 수료 약 6.5개월 → B1 수료 약 12개월 → B2 수료 약 18.7개월

### 총 학습 시간 (수업 + 숙제)

차시당 학습 = 수업 100분 + 숙제 60분 = **160분**

| 레벨 | 수업 | 숙제 | 총 학습 시간 |
|---|---|---|---|
| A1 | 45시간 | 27시간 | **72시간** |
| A2 | 95시간 | 57시간 | **152시간** |
| B1 | 120시간 | 72시간 | **192시간** |
| B2 | 145시간 | 87시간 | **232시간** |
| 합계 | 405시간 | 243시간 | **648시간** |

- 80분 수업 때보다 수업 시간이 **25% (81시간)** 늘었습니다. 기간(개월 수)은 그대로 두고, 늘어난 시간은 **말하기·쓰기 연습을 수업 안으로 가져오는 데** 썼습니다. (예: 1과의 롤플레이, 짝 첨삭은 80분 구성에서는 숙제나 추가 활동이었음)
- 압축된 A1(8과)의 합친 과(2·4·6·8과)도 100분 × 3차시면 두 장면을 무리 없이 다룰 수 있습니다.
- 진도가 느린 반은 복습 주를 1주씩 더 넣어 조정하세요.

### 이력: A1 단축 (14주 → 9주)
원래 12과를 8과로 합치고(2+3, 5+6, 8+9, 11+12과) 중간 복습 주를 뺐습니다. Start Deutsch 1에 필요한 문법은 그대로입니다. 줄어든 5주(15차시)는 다음과 같이 나눴습니다.
- **A2 +1주**: 시작할 때 **A1 다지기 주** – 압축된 A1을 한 번 더 굳히기
- **B1 +2주**: **쓰기·말하기 워크숍** – B1 시험에서 가장 많이 떨어지는 두 영역 집중
- **B2 +2주**: **쓰기·말하기 워크숍** – 논증문·발표·토론 집중 첨삭

### 한 차시 = 1교시 + 2교시

| | 1교시 (50분) · **Input** | 쉬는 시간 | 2교시 (50분) · **Output** |
|---|---|---|---|
| 하는 일 | 복습(5분) → 장면 듣기·읽기 → 문법 **발견** · 규칙 정리 | 10분 권장 | 문법 연습 → 말하기 활동 → 쓰기 / 발음 |
| 교사 역할 | 질문으로 이끌기, 설명은 짧게 | | 활동 진행, 오류 메모 → 끝에 피드백 |

### 한 과 안의 차시 배분 (기본 틀)

**A1 (1과 = 3차시)**
| 차시 | 1교시 | 2교시 |
|---|---|---|
| 1 | 장면 ①② + 문법 ① 발견 | 문법 연습 + 발음 + 말하기 |
| 2 | 장면 ③ + 문법 ②③ | 문법 연습 + 말하기(롤플레이) |
| 3 | 읽기·듣기 + 말하기(인터뷰) | 쓰기 + 짝 첨삭 |

**A2 (1과 = 4차시)**
| 차시 | 1교시 | 2교시 |
|---|---|---|
| 1 | 지난 과 첨삭 피드백 + 장면 ① + 문법 ① | 문법 연습 + 말하기 |
| 2 | 장면 ② + 문법 ② | 문법 연습 + 말하기(롤플레이) |
| 3 | 읽기 + 듣기 | 과제형 말하기 활동 + 발음 |
| 4 | 쓰기 (모범 답안 분석 → 작성) | 짝 첨삭 → 다시 쓰기 + 과 정리·미니 테스트 |

**B1 (1과 = 5차시)**
| 차시 | 1교시 | 2교시 |
|---|---|---|
| 1 | 지난 과 첨삭 피드백 + 장면 ① + 문법 ① | 문법 연습 + 말하기 |
| 2 | 장면 ② + 문법 ② | 문법 연습 + 말하기 |
| 3 | 읽기 (긴 글, 전략 연습) | 어휘 확장 + 요약해서 말하기 |
| 4 | 듣기 (인터뷰·방송) | 시험형 말하기(함께 계획하기·발표) |
| 5 | 쓰기 (이메일·포럼 글 등) | 짝 첨삭 → 다시 쓰기 + 과 정리 |

**B2 (1과 = 6차시)**
| 차시 | 1교시 | 2교시 |
|---|---|---|
| 1 | 지난 과 첨삭 피드백 + 장면 ① + 문법 ① | 문법 연습 |
| 2 | 문법 ② | 어휘(명사화·연어) + 말하기 |
| 3 | 긴 글 읽기 | 요약 + 토론 준비 |
| 4 | 듣기 (강의·인터뷰) | 토론 |
| 5 | 쓰기 계획 + 초안 | 쓰기 완성 |
| 6 | 첨삭 피드백 + 다시 쓰기 | 발표 + 과 정리 |

> 교사가 첨삭하는 쓰기 과제는 **다음 과 첫 차시 1교시 첫 10분**에 돌려주며, 자주 나온 오류를 함께 정리합니다.

### 🔎 44과를 관통하는 수수께끼: Frau Schulze의 사진

| 시점 | 단서 | 함께 배우는 것 |
|---|---|---|
| 1과 | 민준의 일기: “아래층 Frau Schulze는 ‘Hallo’ 대신 ‘Guten Tag’만 한다. 웃지도 않는다.” | du/Sie 문화 |
| 8과 (A1) | WG 파티에 처음 온 Frau Schulze. 하은이 그녀의 집에서 **촛불을 든 젊은 여자와 남자의 흑백 사진**을 봄. “Wer ist das?” – 대답 없음. | 현재완료 (Was hast du gemacht?) |
| 13과 (A2) | 크리스마스 마켓에서 어떤 노래를 듣고 눈물을 보이는 Frau Schulze. | 형용사 어미 (묘사) |
| 19과 (A2) | “Mein Bruder … lebt nicht hier.” 처음으로 가족 이야기. 사진 속 남자는 오빠? | 관계문 (der Mann, **der** …) |
| 22과 (B1) | 하은이 오래된 편지 묶음을 발견 – 서독 소인이 찍힌 편지들. | 과거완료 (Er **war** schon **gegangen**.) |
| **27과 (B1)** | **비밀 공개**: 1984년 오빠가 서독으로 탈출, 1989년 10월 9일 Frau Schulze는 촛불을 들고 월요 시위에 참여. 장벽이 무너진 뒤 5년 만에 재회. 사진은 시위 날 밤의 그녀와 친구. | 과거형으로 이야기하기, 역사 |
| 39과 (B2) | 이민 온 하은과 ‘서쪽으로 간’ 오빠의 이야기가 겹침 – 떠남과 정착에 대한 대화. | 주관적 화법조동사, 정체성 |
| 44과 (B2) | Frau Schulze가 민준과 수진에게 남기는 말 – 사진을 하은에게 선물. | 회고 에세이 |

### 😅 실수가 곧 사건 (한국인 학습자의 실제 오류 활용)

| 과 | 사건 | 학습 포인트 |
|---|---|---|
| 2과 | 수진이 Kita 선생님께 “Ich bin **38**”을 “Ich habe 38”로 말해 웃음 | sein vs haben |
| 3과 | 남편 태호가 마트에서 *Gift*(독)를 선물 코너로 착각 | 가짜 친구(false friends) |
| 6과 | 민준이 의사에게 “Ich **bekomme** …”를 ‘~가 되다’로 오해 | bekommen ≠ become |
| 10과 | 민준이 면접에서 사장에게 du를 써서 분위기 얼어붙음 | du/Sie, 공손 표현 |
| 11과 | 민준이 **Restmüll**에 유리병을 버림 → Frau Schulze 출동 | 분리수거, 3·4격 전치사 |
| 17과 | 수진이 Kita 상담에서 “Mein Sohn **ist** langweilig”(아들은 지루한 아이예요)라고 말해 선생님이 당황 → “Meinem Sohn ist langweilig”(아들이 심심해해요) | 3격 표현 (mir ist kalt/langweilig) |
| 23과 | 민준의 너무 공손한 메시지가 WG에서 오히려 ‘화난 것’으로 오해받음 | 문화 차이, 접속법 2식 |
| 25과 | 병원 첫날, 환자가 “Schwester!”라고 부르자 수진이 ‘누나/언니?’ 하고 두리번거림 | 다의어, 직업 명칭(Pflegefachfrau) |

## 6. 문법 진도 원칙

- Goethe-Institut/**Profile Deutsch**의 레벨별 문법 범위를 따름.
- 처음 나오는 문법은 **필요한 만큼만** 다루고(예: A1 7과의 3격은 전치사 뒤에서만), 다음 레벨에서 **나선형으로** 확장.
- 문법은 반드시 그 과 이야기 속 문장으로 처음 등장 → 학생이 맥락 속에서 먼저 만남.
