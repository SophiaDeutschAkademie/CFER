# 교재 설계 개요 – *Der falsche Koffer*

## 1. 기본 콘셉트

- **장르: 코지 미스터리(Cozy Krimi) + 휴먼 드라마** – 라이프치히 중앙역에서 바뀐 여행가방 하나가 1989년의 비밀로 이어집니다. 폭력 없는 추리, 따뜻한 이웃, 매 과 끝의 궁금증.
- **추리 = 언어 과제**: 탐정이 하는 일(묻기 → 묘사하기 → 과거 재구성하기 → 증언 전하기 → 추측하기)이 A1 → B2 문법 진도와 그대로 겹칩니다. 재미있는 장면은 반드시 그 과의 핵심 표현이 꼭 필요한 장면입니다.
- **대상 학습자**: 성인 – ① **대학 유학 준비생** ② **아이를 둔 이민 가정**. 두 그룹이 모두 “내 이야기”로 느끼도록 **주인공을 두 명**으로 두고, 각자 **다른 단서**를 쥐게 합니다.
- **통합형**: 한 챕터 안에서 *듣기/읽기로 장면을 접하고 → 문법을 발견하고 → 말하기·쓰기로 직접 써 보는* 흐름. 매 과 끝 **Tagebuch(일기)**가 다음 과로 이어지는 다리 역할을 합니다.
- **CEFR 정렬**: 각 챕터에 CEFR Can-do 목표, 레벨 마지막은 Goethe-Zertifikat 시험 형식. CEFR 2020 보완판의 **중개하기(Sprachmittlung)**도 매 과에 포함합니다.
- **한국인 학습자 맞춤**: 문법 설명은 한국어로, 한국어 화자가 자주 틀리는 부분을 따로 표시합니다. 한국인이 실제로 하는 실수는 이야기 속 **사건**으로도 활용합니다.
- **첨삭 중심 쓰기**: 쓰기 과제마다 모범 답안 + 첨삭 체크리스트 + 자주 나오는 오류 예시.

### 🗣️ 언어 현실성 원칙 – “한국인끼리는 한국어로”

| 원칙 | 교재에서 |
|---|---|
| **① 생활 공간 분리** | 민준은 사설 어학원 집중반, 수진은 이민자 통합 과정(Integrationskurs – 아이 돌봄 지원)에 다닙니다. 각 반의 국적이 다양해서 **공용어는 독일어**. |
| **② 한국인끼리는 한국어** | 민준과 수진이 만나는 장면은 교재에 **한국어로** 짧게 싣습니다. 억지로 독일어로 대화시키지 않습니다. |
| **③ 중개하기 과제** | 둘이 한국어로 나눈 정보를 Jonas·경찰·Frau Schulze에게 **독일어로 전달**해야 하는 상황 → 매 과 **🔁 Sprachmittlung** 활동. 실제 이민 생활에서 매일 하는 일입니다. |
| **④ 연결 고리는 독일어 사용자** | 이웃 Frau Schulze, WG 친구들, 그리고 **딸 하은**. 하은은 독일어가 가장 빨리 늘어 부모의 통역사가 되고, 집에서는 한국어와 독일어를 섞어 씁니다. |
| **⑤ 남편 태호는 회사에서 영어** | 독일어가 가족 중 가장 느림 – 이민 가정의 현실적인 갈등과 웃음. |

## 2. 수업 회차 (주 3회 × 100분 기준)

**1차시 = 100분 (1교시 50분 + 2교시 50분) · 1주 = 3차시(300분) · 숙제 차시당 60분**

| 레벨 | 챕터 | 1과당 차시 | 본 수업 | 복습·워크숍·시험 대비 | 레벨 합계 | 기간 | 레벨 끝 시험 |
|---|---|---|---|---|---|---|---|
| **A1** | 1–8 | **3차시** (= 1주) | 24차시 | 3차시 (모의시험 1주) | **27차시 · 45시간** | **9주 (약 2개월)** | Start Deutsch 1 |
| **A2** | 9–20 | **4차시** (3과 = 4주) | 48차시 | 9차시 (A1 다지기 1주, 14과 후 복습 1주, 모의시험 1주) | **57차시 · 95시간** | **19주 (약 4.4개월)** | Goethe A2 |
| **B1** | 21–32 | **5차시** (3과 = 5주) | 60차시 | 12차시 (26과 후 복습 1주, 쓰기·말하기 워크숍 2주, 모의시험 1주) | **72차시 · 120시간** | **24주 (약 5.5개월)** | Goethe B1 |
| **B2** | 33–44 | **6차시** (1과 = 2주) | 72차시 | 15차시 (38과 후 복습 1주, 쓰기·말하기 워크숍 2주, 모의시험 2주) | **87차시 · 145시간** | **29주 (약 6.7개월)** | Goethe B2 |
| **합계** | 44과 | | 204차시 | 39차시 | **243차시 · 405시간** | **81주 (약 18.7개월)** | |

> 한 달 ≈ 4.3주로 계산. 누적: A1 수료 약 2개월 → A2 수료 약 6.5개월 → B1 수료 약 12개월 → B2 수료 약 18.7개월

### 총 학습 시간 (수업 + 숙제)

차시당 학습 = 수업 100분 + 숙제 60분 = **160분**

| 레벨 | 수업 | 숙제 | 총 학습 시간 |
|---|---|---|---|
| A1 | 45시간 | 27시간 | **72시간** |
| A2 | 95시간 | 57시간 | **152시간** |
| B1 | 120시간 | 72시간 | **192시간** |
| B2 | 145시간 | 87시간 | **232시간** |
| 합계 | 405시간 | 243시간 | **648시간** |

- 80분 수업 때보다 수업 시간이 **25% (81시간)** 늘었습니다. 기간(개월 수)은 그대로 두고, 늘어난 시간은 **말하기·쓰기 연습을 수업 안으로 가져오는 데** 썼습니다. (예: 1과의 롤플레이, 짝 첨삭은 80분 구성에서는 숙제나 추가 활동이었음)
- 압축된 A1(8과)의 합친 과(2·4·6·8과)도 100분 × 3차시면 두 장면을 무리 없이 다룰 수 있습니다.
- 진도가 느린 반은 복습 주를 1주씩 더 넣어 조정하세요.

### 이력: A1 단축 (14주 → 9주)
원래 12과를 8과로 합치고(2+3, 5+6, 8+9, 11+12과) 중간 복습 주를 뺐습니다. Start Deutsch 1에 필요한 문법은 그대로입니다. 줄어든 5주(15차시)는 다음과 같이 나눴습니다.
- **A2 +1주**: 시작할 때 **A1 다지기 주** – 압축된 A1을 한 번 더 굳히기
- **B1 +2주**: **쓰기·말하기 워크숍** – B1 시험에서 가장 많이 떨어지는 두 영역 집중
- **B2 +2주**: **쓰기·말하기 워크숍** – 논증문·발표·토론 집중 첨삭

### 한 차시 = 1교시 + 2교시

| | 1교시 (50분) · **Input** | 쉬는 시간 | 2교시 (50분) · **Output** |
|---|---|---|---|
| 하는 일 | 복습(5분) → 장면 듣기·읽기 → 문법 **발견** · 규칙 정리 | 10분 권장 | 문법 연습 → 말하기 활동 → 쓰기 / 발음 |
| 교사 역할 | 질문으로 이끌기, 설명은 짧게 | | 활동 진행, 오류 메모 → 끝에 피드백 |

### 한 과 안의 차시 배분 (기본 틀)

**A1 (1과 = 3차시)**
| 차시 | 1교시 | 2교시 |
|---|---|---|
| 1 | 장면 ①② + 문법 ① 발견 | 문법 연습 + 발음 + 말하기 |
| 2 | 장면 ③ + 문법 ②③ | 문법 연습 + 말하기(롤플레이) |
| 3 | 읽기·듣기 + 말하기(인터뷰) | 쓰기 + 짝 첨삭 |

**A2 (1과 = 4차시)**
| 차시 | 1교시 | 2교시 |
|---|---|---|
| 1 | 지난 과 첨삭 피드백 + 장면 ① + 문법 ① | 문법 연습 + 말하기 |
| 2 | 장면 ② + 문법 ② | 문법 연습 + 말하기(롤플레이) |
| 3 | 읽기 + 듣기 | 과제형 말하기 활동 + 발음 |
| 4 | 쓰기 (모범 답안 분석 → 작성) | 짝 첨삭 → 다시 쓰기 + 과 정리·미니 테스트 |

**B1 (1과 = 5차시)**
| 차시 | 1교시 | 2교시 |
|---|---|---|
| 1 | 지난 과 첨삭 피드백 + 장면 ① + 문법 ① | 문법 연습 + 말하기 |
| 2 | 장면 ② + 문법 ② | 문법 연습 + 말하기 |
| 3 | 읽기 (긴 글, 전략 연습) | 어휘 확장 + 요약해서 말하기 |
| 4 | 듣기 (인터뷰·방송) | 시험형 말하기(함께 계획하기·발표) |
| 5 | 쓰기 (이메일·포럼 글 등) | 짝 첨삭 → 다시 쓰기 + 과 정리 |

**B2 (1과 = 6차시)**
| 차시 | 1교시 | 2교시 |
|---|---|---|
| 1 | 지난 과 첨삭 피드백 + 장면 ① + 문법 ① | 문법 연습 |
| 2 | 문법 ② | 어휘(명사화·연어) + 말하기 |
| 3 | 긴 글 읽기 | 요약 + 토론 준비 |

| 6 | 첨삭 피드백 + 다시 쓰기 | 발표 + 과 정리 |

> 교사가 첨삭하는 쓰기 과제는 **다음 과 첫 차시 1교시 첫 10분**에 돌려주며, 자주 나온 오류를 함께 정리합니다.

| 과거 사건 재구성 | 과거형, **과거완료**, 수동태 (Die Briefe **wurden** geöffnet.) | B1 |
| 공식 서류 신청하기 | 공식 서신, zu-부정사 | B1 |
| 문서·증언 전하기 | **접속법 1식** (IM „Rose“ berichtete, er **plane** …) | B2 |
| 추측하고 결론 내리기 | **추측의 화법조동사** (Sie **soll** IM gewesen sein. Er **muss** es gewusst haben.) | B2 |

### 😅 실수가 곧 사건 (한국인 학습자의 실제 오류 활용)

| 과 | 사건 | 학습 포인트 |
|---|---|---|
| 2과 | 수진이 통합 과정에서 “Ich **habe** 38”이라고 말함 | sein vs haben |
| 3과 | 남편 태호가 *Gift*(독) 표시를 선물 코너로 착각 | 가짜 친구 단어(false friends) |
| 6과 | 의사가 “Sie **bekommen** ein Rezept”라고 하자 민준이 ‘제가 처방전이 된다고요?’ | bekommen ≠ become |
| 10과 | 민준이 카페 면접에서 사장에게 du를 씀 | du/Sie, 공손 표현 |
| 11과 | 민준이 유리병을 Restmüll에 버림 → Frau Schulze 출동 | 분리수거, 3·4격 전치사 |
| 17과 | 수진이 Kita 상담에서 “Mein Sohn **ist** langweilig”(아들은 지루한 아이예요) | 3격 표현 (Mir ist langweilig.) |
| 23과 | 민준의 지나치게 공손한 메시지를 WG 친구가 ‘화났다’고 오해 | 접속법 2식, 문화 차이 |
| 25과 | 병원 첫날, 환자가 “Schwester!”라고 부르자 수진이 ‘언니?’ 하고 두리번 | 다의어, 직업 명칭 |

### 다루는 방식에 대한 원칙
- **폭력·공포 묘사 없음**: 체포·수감은 과거의 이야기로 전달될 뿐, 장면으로 보여 주지 않습니다.
- **악역 없음**: Ingrid는 아들의 진학을 볼모로 압박받은 사람으로 그립니다. 주제는 고발이 아니라 **기억, 이해, 용서**.
- **실제 역사·장소는 정확하게**: 1989년 10월 9일 월요 시위, 니콜라이 교회, 슈타지 박물관 Runde Ecke, 슈타지 문서 열람 절차(현재 연방기록원 소관), 수감자 석방 거래(Häftlingsfreikauf)는 실제 사실에 맞춰 씁니다. 인물과 병원은 가상입니다.

## 5. 챕터 구성 틀 (모든 챕터 공통)

| 순서 | 섹션 | 하는 일 | 기능 |
|---|---|---|---|
| 0 | **Lernziele** | 이번 과 Can-do 목표 확인 | – |
| 1 | **Einstieg** | 그림/상황 보고 예측하기 | 말하기 |
| 2 | **Teil A–C (Szenen)** | 이야기 장면(대화문/글) → 이해 문제 | 듣기·읽기 |

| 4 | **Wortschatz** | 주제 어휘 + 필수 표현(Redemittel) | 어휘 |
| 5 | **Lesen** | 장면과 이어지는 실용 텍스트(메시지, 안내문, 기사 등) | 읽기 |
| 6 | **Hören** | 대본 제공(교사가 읽거나 녹음) | 듣기 |
| 7 | **Sprechen** | 짝·그룹 활동, 롤플레이 | 말하기 |
| 7+ | **🔁 Sprachmittlung** | 한국어 장면(민준↔수진)의 내용을 독일인 등장인물에게 독일어로 전달 | 중개하기 |
